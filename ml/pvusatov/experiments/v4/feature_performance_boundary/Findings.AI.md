# Feature block boundary parity: bounded engineering evidence

The unchanged grouped-photometry research prototype matched the unchanged original extractor exactly on all 30 frozen engineering boundary cases and two empty-pool controls. The comparison covered 172,158 candidate rows and 5,164,740 values in each 30-column matrix. Float64 bits, float32 bits, candidate IDs, complete diagnostics, semantic metadata, actual C596 score bits, and complete stable score order all matched. No observed differences, exceptions, discarded cases, or support-validation failures occurred. This closes the specific untested 4096-row grouping boundary for these inputs; it does not establish global equivalence or authorize promotion.

The prospective plan is `Plan.AI.md`. The write-once machine protocol is `protocol.json`, SHA256 `0350987419ab5e7a202cda7b342852c0095b0c9972aa8939a4b8ccdcae4dde55`. Plan and source/model bindings were frozen before any numeric fixture generation. Its 30 cases are the Cartesian product of 8/16 epochs, homogeneous valid-photometry group sizes 4095/4096/4097/8192/8193, and three fixed scenarios. These exercise a partial first block, exact first block, second-block remainder, exact second block, and third-block remainder. Four additional measured rows per case exercise two unsupported edge paths and two shorter paths. Returned original per-candidate validity diagnostics and prototype group counts independently confirm each declared homogeneous boundary group.

The finite-noise scenario uses signed Gaussian arrays with varying epoch noise and no quality masks. The signed-quality scenario adds signed spatial/epoch background plus aligned boolean outlier/bloom masks. The finite-support scenario additionally supplies NaN-masked rows, a fully empty final epoch, and a constant-zero raw penultimate epoch. Candidates omit the entirely empty epoch; zero raw-noise epochs retain measured zero SNR. Boundary residual valid-count groups are 8/16 in the first two scenarios and 7/15 in the finite-support scenario. Both unsupported edge controls have no valid residual photometry and retain explicit missing-statistic diagnostics. The two empty-pool controls retain shape (0,30), no IDs/diagnostics, and no fabricated score rows. All30 nonempty cases contain actual C596 score ties, so full stable-order comparison exercises tie handling as well as score equality.

These are numeric engineering arrays and measured sampling paths, not real field detections, newly evaluated astronomical cases, or label-bearing samples. The harness instantiates the actual immutable `Candidate` class. It samples finite raw intensities along deterministic finite interior/edge paths, measures signed SNR from robust frame noise and shape ratios from smoothed intensities, and fits path RMS/speed from coordinates and physical times. It uses the actual inherited six Candidate features and requires them all to be finite. These paths have not passed the detector's peak-selection/linking cuts and support no claim about completeness, purity, sensitivity, source discovery, or real candidate populations.
