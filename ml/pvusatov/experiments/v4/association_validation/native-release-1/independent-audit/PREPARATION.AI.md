# Native independent audit preparation

The streaming checker is prepared but has not inspected any native result manifest, cache, partial outcome, or producer report. Execution waits for the root's report-complete handoff. Preparation inspected frozen source/schema and the already released handoff/authorization metadata only. No FITS files, pixel arrays, model inference, feature extraction, simulation, fitting, or producer accounting functions are used.

The checker derives from the separately implemented synthetic auditor, with native-specific geometry, common-attribution, identity, and parent accounting. It binds frozen R2 `ae981b56f43c8a14cd6dee9ce61c48853ea7c90b63eca8ddcf586e0a3e3dbbdd` and root release handoff `6005fd136cdab828cac9c786c18fce2c4977289924f7ff94df3a3ddf92671abb`. It independently reconstructs 12 reserved parent seeds, all 1,620 fixed injection identities, and 12 controls. The released 96 distinct physical observations and exclusion/cohort declarations are checked as metadata; this numeric audit does not re-open raw FITS to repeat their separate release audit.

After closure, every available full/compact hash, stable pair-exclusive decision, spatial label within 1.5 pixels at all candidate epochs, minimum three epochs, actual matched-epoch truth span, and unique recovered/resolved/unresolved count is recomputed. Control candidate geometry is tested against each injection truth separately for both policy-retained control pools. Common attribution requires absence of a match in both pools. Control workload remains UNKNOWN and is not interpreted as false positives or survey precision.

The checker keeps one full field and compact field at a time, one parent's retained control geometry, and small summaries/hashes for the closed records. It independently reconstructs all-planned and common-attributable macro/micro results, per-parent counts, producer speed/brightness/parent strata, and 10,000 paired whole-parent bootstrap draws with seed `2026111502`. Truth-positive parents define macro denominators. Errors remain represented; error-containing primary aggregates are unavailable rather than resampled or dropped. Missing, duplicate, changed identities, hash mismatches, or accounting mismatches fail the audit.

Native fields have no `cadence_family` value in the frozen schema. The audit therefore records exact parent `times_hours` hashes and epoch-spacing/span descriptors alongside parent strata, without inventing cadence categories. Producer native reporting emits parent, speed, and brightness strata only.

Five analytic fixture tests pass: the 1.5-pixel boundary and tie rule, maximum distance across actual matched epochs, stable pair pruning and two-link overlap, unique truth resolution accounting, both-policy control attribution, and paired parent bootstrap with an empty common cohort. These fixtures contain no native evidence and do not validate actual native results.

The checker uses one math thread, an eight-GiB address-space limit, and a 3,600-CPU-second ceiling. Prefix rebasing for repository and derived-cache references preserves original provenance paths and expected digests. Existing synthetic audit artifacts remain untouched.
